# Der Workshop, Seite für Seite

[English](README.md)

Jede Seite hat zwei Spuren: Der Text erklärt, was passiert, und die Abschnitte
„Unter der Haube“ liefern Bytes, Regeln und Vertrauensmodell für alle, die das
wollen.

## Hier anfangen

- [Erste Schritte](getting-started.de.md): was Sie brauchen, wie Sie eine Lektion
  starten, zur nächsten wechseln und Ihre Änderungen prüfen.
- [Wallet und Sicherheit](wallet-and-safety.de.md): Die App arbeitet mit echtem
  Geld im Doichain-Mainnet. Was Sie vor dem Signieren prüfen und was die Server
  sehen.

## Hintergrund

- [Die Ideen dahinter](concepts.de.md): Kette, Coins, Namen, PSBT und ein
  Glossar, für alle, die aus der Web-Welt kommen.
- [Unter der Haube](under-the-hood.de.md): Namens-Skripte Byte für Byte, die
  Konsensregeln seit Block 431.017, Gebühren, Signaturen und was Sie weiter
  vertrauen.
- [Eine Lektion auf IPFS veröffentlichen](ipfs.de.md): bauen, zum eigenen Knoten
  hinzufügen, erreichbar halten.
- [Für Maintainer](maintainers.de.md): der Workspace, was ins gemeinsame Paket
  gehört, die Prüfungen und wie die Lektionen veröffentlicht werden.

Jede Seite hier hat einen englischen Zwilling, verlinkt ganz oben.
